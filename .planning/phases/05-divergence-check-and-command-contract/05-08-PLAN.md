- $defs.success: required and only: command (const "check"), schema_version (const 1), configured (boolean), workspace {branch bytes, tip string pattern ^[0-9a-f]{40}([0-9a-f]{24})?$}, integration {branch bytes, ref bytes, tip as workspace.tip}, staleness {applies boolean, reason string|null, ref_moved_at integer|null, ref_moved_age_seconds integer|null, ref_moved_reason string|null, fetched_at integer|null, fetched_age_seconds integer|null, fetched_reason string|null}, hooks {path bytes|null, checked boolean, reason string|null}, problems: array of {kind enum [undeclared_added, undeclared_modified, undeclared_deleted, stale_only, stale_modified, redundant_builtin, hook_not_executable], path bytes, detail string|null}. Every object additionalProperties false.
- $defs.failure: required and only: command (const "check"), schema_version (const 1), error {kind string minLength 1, message string, exit_code integer minimum 2 maximum 6}.
