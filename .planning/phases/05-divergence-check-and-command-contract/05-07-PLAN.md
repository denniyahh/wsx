Staleness contract:
- pub enum TimeRead { NotRead, At(i64), Unknown(String) }, Unknown holding the reason the time is null; pub struct Staleness { pub applies: bool, pub ref_moved_at: TimeRead, pub fetched_at: TimeRead, pub now: i64 }; Report gains pub staleness: Staleness; run reads SystemTime::now once (as whole unix seconds) and passes it in.
- applies is true exactly when integration.full_ref begins with refs/remotes/; then staleness::read calls repo.ref_moved_at(git, &full_ref) and repo.fetched_at() and passes each answer through one pure function, time_of (generic over the error's Display, so its test needs no git): Ok(Some(t)) is At(t); Ok(None) is Unknown("no reflog for <R>") or Unknown("no FETCH_HEAD"); Err(e) is Unknown("the reflog of <R> could not be read: <e>") or Unknown("FETCH_HEAD could not be read: <e>"). Neither error reaches run's Result (D-13, orchestrator decision): the reflog child failing, a FETCH_HEAD stat error other than NotFound, and a stray file under <common>/worktrees/ (05-03 answers Io for its <entry>/FETCH_HEAD) all end as Unknown. Else neither read runs and both are NotRead.
- JSON, before hooks: staleness {applies, reason, ref_moved_at, ref_moved_age_seconds, ref_moved_reason, fetched_at, fetched_age_seconds, fetched_reason}. applies false: reason "<R> is a local branch; it is not fetched", the other six null. applies true: reason null; At(t) gives t and now minus t with its reason null; Unknown(r) gives null, null and r.
- Human diagnostic, every run: applies true: "wsx check: integration ref R: <moved>; <fetched>" with <moved> "last moved <age> ago (reflog)" or, when Unknown, its reason (such as "no reflog for R"), and <fetched> "last fetch <age> ago (FETCH_HEAD)" or its reason (such as "no FETCH_HEAD"); applies false: "wsx check: integration ref R is a local branch; staleness does not apply".
- age_text(seconds): 86400 or more "<d>d <h>h"; 3600 or more "<h>h <m>m"; 60 or more "<m>m <s>s"; else "<s>s"; a negative value "0s".
</context>
