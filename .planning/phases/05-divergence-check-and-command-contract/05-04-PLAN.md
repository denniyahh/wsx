Rules (D-01, D-05, DIV-01, DIV-02):
- Built-ins first: a change whose path a built-in covers is skipped; an entry a built-in covers is RedundantBuiltin with detail Some("<only|modified> E is already personal as the built-in Bi") and gets no stale check. Its human line is "redundant declaration: " followed by the detail.
- Added: declared iff an only entry covers it (05-01). Modified or TypeChanged: declared iff a modified entry's path equals it, else UndeclaredModified. Deleted: the same, else UndeclaredDeleted.
- Only entry: StaleOnly when Repo::lookup_paths at model.integration.tip answers Some for its path. Modified entry: StaleModified when no change's path is covered by the entry (manifest::covers, over every change, built-in or not).
- Entries are deduplicated on (kind, path) before judging, keeping the first. Problem order: group (undeclared, stale, hooks), then path bytes, then kind in ProblemKind declaration order; ProblemKind is declared in the D-11 order.
- evaluate stays pure: run gathers changes and the set of carried only paths, evaluate judges.
</context>
