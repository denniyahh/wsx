- Files: every *.rs under the given src root, sorted, read as bytes; a file that is not UTF-8 or that proc_macro2::TokenStream::from_str refuses is a finding "cannot tokenize <path>: <error>".

- Literal test, on the literal's source text (Literal::to_string): contains ROADMAP.md, STATE.md, .planning/config.json or devflow.toml; or contains .claude or .codex with the byte before it one of a double quote or a slash and the byte after it one of a double quote or a slash.
- Finding text: "<path relative to the root>: literal <literal> names <name>, a GSD, devflow or agent file wsx must not read (IF-02)".
