<objective>
Give the fixture its other two layouts (a repo with no GSD files, and a fork with separate base
and push remotes), each proven by a test, and declare the whole module tree so every later plan
works in files it alone owns.

Purpose: the HARN-06 fork and no-GSD scenarios in 02-10 to 02-14 stand on these layouts, so a
layout that silently carried `.planning`, or a fork whose push remote held the integration branch,
would make those scenarios meaningless. The module tree lets four plans run in parallel later
without touching `main.rs`.
Output: four layout tests and the builder methods in `fixture.rs`, nine header-only module files,
and the widened `main.rs`.
</objective>
