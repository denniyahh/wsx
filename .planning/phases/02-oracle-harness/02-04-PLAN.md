<objective>
Prove the vendored oracle is what it claims to be and that the patch is the only change: a blob
check against the recorded devflow commit, a patch check with recorded post-patch blobs, the
fail-loud adapter variable, each with a control that must trip, and a README that records
provenance and attribution in words a reviewer can check.

Purpose: HARN-01 requires the oracle "MIT-attributed and adapted by one documented patch". A
silently altered script, or a patch that silently did not apply, would make every recorded oracle
outcome fake evidence.
Output: `tests/harness/provenance.rs` (eight tests) and `tests/oracle/README.md`.
</objective>
