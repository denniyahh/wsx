Decisions this plan implements: CONTEXT "Each script has a self-test scenario" (HARN-01), "The pre-push hook is vendored whole. It is driven the way git drives it", and CONTEXT "A scenario names an abstract action ... Each implementation has an adapter". 02-05's parity rule applies: where the oracle and the intended wsx behaviour agree on the safety outcome, the case is Parity and its expected outcome is the oracle's observed one; otherwise it is `fixed:` with the oracle's observed outcome recorded.

Recording rule for every `fixed:` case in this phase: write the Rust expected outcome from the requirement named in the scenario's doc comment, never from the oracle run. To obtain the oracle's outcome, run the scenario once with the case temporarily Parity, read the observed outcome printed with the mismatch, and transcribe it into `OracleSide::Recorded(...)` with `Class::Fixed { defect }`. The oracle test then re-runs the script on every run and must reproduce the record exactly.

Oracle mapping facts (from the scripts):
- `phase-worktree.sh <N> [--no-sync]` creates `feature/phase-<N>` at `<repo root>/.worktrees/phase-<N>` from the only `workspace/*` branch (or `WORKSPACE_BASE`), syncs first when run from the workspace checkout, and needs `### Phase <N>:` in `.planning/ROADMAP.md`.
- `check-workspace-divergence.sh [BASE_REF]` compares `BASE_REF` with `HEAD` of the checkout it runs in and reads `.workspace-divergence` from the working tree.
- `cut-pr-branch.sh [--phase N] [PR_BRANCH] [BASE_BRANCH]` with env `BASE_REMOTE` and `WORKSPACE_BASE`; on a `feature/phase-N` branch it switches to phase mode by itself; it checks the PR branch out in the checkout it runs in.
- `hooks/pre-push <remote> <url>` reads ref lines on stdin, checks only `develop`, `main`, `feature/*`, `fix/*`, `chore/*`, `release/*` refs, bounds a new ref by `--not --remotes=origin`, and, when `.workspace-divergence` exists in its working directory, runs the divergence check against `origin/develop`. Push from a checkout of the integration branch to test the personal-path policy alone; push from the workspace checkout to exercise that tail.

Shell note: every command in this plan is bash.
