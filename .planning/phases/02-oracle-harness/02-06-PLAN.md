<objective>
Pin the coverage tool and the toolchain component it needs, and prove once, with two negative
controls, that `cargo llvm-cov` sees code that only the spawned `wsx` binary executes when the
harness passes `LLVM_*` through.

Purpose: success criterion 2 and HARN-02 require coverage of the spawned binary. Integration tests
never link the crate, so the only way a line of `src/main.rs` is covered is through a spawned
process; a harness that drops `LLVM_*` would report zero coverage and litter fixtures with profile
files.
Output: the llvm-tools component in `rust-toolchain.toml`, the cargo-llvm-cov pin, two tests in
`tests/harness/coverage.rs`, and the recorded one-time proof.
</objective>
