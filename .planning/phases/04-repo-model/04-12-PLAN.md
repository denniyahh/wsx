<objective>
Close the one gap phase 4's verification found (CR-01, CONF-07) by the rule the operator chose on
2026-11-16, which amends D-22: when replace refs are in use at all, the model refuses, whatever their
shape. In a configured repo, `build` refuses before its first object read when anything is under
`refs/replace/` in the common dir, when `packed-refs` holds the text `refs/replace/`, or when either
reader's replace base is set to anything else; `Repo::discover` refuses a `GIT_REPLACE_REF_BASE`
other than `refs/replace/` before gix opens the repository, because some values make gix's open
fail first. The guard reads no ref name and parses no record, so
no difference in how git and gix parse replace refs can make wsx read other `.wsx.conf` bytes than
git. Then run the phase's mutation, coverage and container gates on the new tip.

(nested names, symlinks, special files, unsorted or duplicate `packed-refs` records, tag and tree

by presence is bounded.
