Close a fail-open path found while planning: with `GIT_CONFIG` set, `git config` reads only that file
(probe on git 2.56.1: a repo's own `wsx.sourceBranch=dev` was not printed, and the variable's file came

repository as not configured and lose its remotes, while `git remote add` and every other command read
the repository's config. `GIT_CONFIG` is on git's `--local-env-vars` list, so a child aimed at another
worktree already loses it, but Phase 3 keeps it for a child aimed at wsx's own worktree. The operator
chooses the fix; this plan then implements it.

Purpose: from Phase 6 the guard exits 0 in a repository that reads as not configured (D-16), so this
path would let a personal file through.
