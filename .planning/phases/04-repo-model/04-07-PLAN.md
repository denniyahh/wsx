The integration-branch chain. `wsx.baseRef` wins with no fallback; otherwise `develop`, `next`, then
the remote default, reading the base remote's tracking refs only, and local branches only when
there is no base remote. If nothing exists, the error lists what was tried and the fixes.

Purpose: Success Criterion 2. The base decides what a PR cut replays and what `wsx check` compares;
guessing it silently would put wrong history in a PR.
Output: the finished `integration` and `is_branch_name`, plus the ref-read tests against git.
</objective>
