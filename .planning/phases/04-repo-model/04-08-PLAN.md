<objective>
The workspace branch and the configured state. `wsx.sourceBranch` names the branch; without it, the
only local `workspace/*` or `personal/*` branch is inferred and the repo stays not configured. Zero
or several candidates is an error that lists them, and only for commands that need a branch.

Purpose: Success Criterion 3 and the second half of 5. The guard must be able to tell "not
configured" apart from "configured and broken" without classifying errors.
Output: `refs_directly_under`, candidate selection, `RepoModel::require`.
</objective>

<assumption_delta_decision>
Noun: the workspace branch, one per repository, carried as `Model::workspace_branch`.
Decision: no-change.
Rationale: the fallback is a second way to find that one branch, not a second branch or a second source of truth: `wsx.sourceBranch` stays the only thing that makes a repo configured (D-15), and zero or several candidates is a refusal rather than a plural model (D-21). `RepoModel` already keeps the two states apart, so nothing needs promoting.
Invariant test: `no_source_branch_is_not_configured` already goes red if a fallback match ever starts counting as configured.
</assumption_delta_decision>
