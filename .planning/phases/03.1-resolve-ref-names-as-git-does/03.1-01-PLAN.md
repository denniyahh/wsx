<objective>
Tracer slice for the phase. One read, `Repo::merge_base`, takes commit ids end to end: the git
CLI names the ids, `ObjectId::to_gix` decodes their hex, `Repo::peel_commit` peels each to its
commit, and gix's merge-base answers. The RED test shows the defect on today's code: given a
ref named like `describe` output, wsx's merge-base differs from git's. The GREEN commit makes it
equal. The second task fixes `peel_commit`'s contract against git for every object kind and puts
the new test suite under the runner-`GIT_DIR` check.

Purpose: if id inputs, the peel and the oracle-supplied ids cannot carry one read, the phase
learns it after one commit. 03.1-02 completes the peel's refusals, 03.1-03 moves the other three
reads, and 03.1-04 removes name resolution and bans the parser (D-01, D-02, D-03).
Output: `src/git/refs.rs`, `ObjectId::to_gix`, `merge_base` on ids, the describe-shaped fixture,
seven peel tests, a three-suite `DISCOVERING_SUITES`.
</objective>
