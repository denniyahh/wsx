<objective>
Criterion 3 in the unit tests: a reftable repository is refused with a message naming reftable,
while the same history in a files-backend repository opens. The refusal comes from
`extensions.refStorage` before any ref is touched (gix 0.90 opens reftable and fails only when it
decodes a ref), and gix's own unsupported-backend error maps to the same refusal as a backstop.

Purpose: CONTEXT's "a refusal must not be silent": a repository wsx cannot read must never open
with refs missing.
Output: the configuration check, the backstop mapping and eight tests in `src/git/repo.rs`.
</objective>
