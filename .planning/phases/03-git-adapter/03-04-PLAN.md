<objective>
Make the single entry point enforceable: every other way to open or discover a repository with
gix is banned through `clippy.toml`, the ban list is pinned so it cannot silently go stale, and
both controls (an unsanctioned call fails, a stale path fails) are run. Also prove the SHA-256
support CONTEXT decided on with its one open test.

Purpose: CONTEXT makes `discover_with_environment_overrides_opts` the only way wsx opens a
repository, because any other call ignores the hook environment or opens a sibling with the
hook's index. A ban that only warns on a stale path (RESEARCH Pitfall 2) would let that rule rot
on the next gix upgrade.
Output: 14 ban entries, the pin test, the SHA-256 test.
</objective>
