Grow the spawn helper to GIT-02's rules and CONTEXT's version gate: git older than 2.54 is
refused once, on the first spawn, naming what was found; a child aimed at any worktree other than

- Worktree-root contract: the `worktree` argument of `run` and `command`, and the path given to `with_own_worktree`, must be a worktree root. Own-versus-other is exact canonical equality, so a subdirectory of wsx's own worktree counts as another worktree and loses the hook's environment (the safe direction, never a silent sibling leak). The `///` docs of those three items state it, including the literal phrase `must be a worktree root`.
- Private `fn base_command(&self, worktree: &Path, args: &[OsString]) -> Command`: `env_clear`, the whole snapshot, `current_dir`, `Stdio::null()`, args. Used for `git --version` and `git rev-parse --local-env-vars`, which need no removal (both work without a repository; RESEARCH line 353).
- `fn command(&self, worktree: &Path, args: &[OsString]) -> Result<Command, Error>`: canonicalises the target (`Error::Io` on failure), and when it differs from the own worktree (or there is none) drops every snapshot pair whose key is on the removal list; otherwise keeps the snapshot whole. The list is fetched on first need only (the first call aimed at a worktree other than the own one) through `base_command(worktree, ["rev-parse", "--local-env-vars"])`, then cached; a child aimed at the own worktree never triggers it. Program `git`, args exactly as given, `current_dir` the target as passed, null stdin.
- `run`: ensure the version (once), then `command(..)?.output()`, then the 03-01 status mapping. The version check is therefore always the helper's first spawn, before any list query.
- `const MIN_GIT_VERSION: (u32, u32) = (2, 54);` with a `///` doc naming CONTEXT's decision; `fn parse_git_version(output: &[u8]) -> Option<(u32, u32)>`: first line, the token after `git version `, its first two dot-separated parts as `u32`, anything after them ignored.

Decisions this plan implements (03-CONTEXT.md, by heading):
- "Running the git binary": the removal list comes from `git rev-parse --local-env-vars` at runtime, queried once per process (one helper per process in production); removal applies to any child whose target worktree differs from wsx's own; every child gets a null stdin and an explicit working directory; the helper adds nothing that bypasses hooks or signing; git ≥ 2.54 is checked once, on the first `git` spawn, and an older git is refused naming the version found and required.
- "Paths are canonicalised once": own-versus-other is decided by canonical paths.
