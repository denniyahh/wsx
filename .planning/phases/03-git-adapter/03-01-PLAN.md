<objective>
Tracer slice for the phase: wsx opens a real repository through its single gix entry point from a
subdirectory, answers one read query (merge-base) from gix, and gets git's answer for the same
query through its own `git` spawn helper, and the two agree on a criss-cross history with a
clock-skewed commit. Every layer the phase builds is crossed once: the pinned gix dependency and
its license policy, the module skeleton and its dead-code expectation, the error type, the
repository resolver, one read, the spawn helper and the unit-test support. The second task fixes
the whole `Error` interface so later plans construct variants without touching `mod.rs`.

Purpose: if gix 0.90.0 cannot be built under the license policy, if the module cannot pass
clippy without a caller, or if gix's merge-base disagrees with git on a criss-cross, the phase
learns it after one commit, not after ten.
Output: `src/git/` with its five files, the gix dependency, the widened license list, three tests.
</objective>

The criss-cross fixture (`criss_cross`), built in `<scratch root>/repo` with `git init -q -b main`, every commit dated through `dated` (author and committer date `@<epoch> +0000`), message passed with `-m`:
1. C0 on `main` at `T0`: `a.txt` = `a`, `f/x` = `x`, `p` = `p`, `q` = `q` (each newline-terminated), message `c0 base`; then `git branch feat`.
2. C1 on `main` at `T0 + 1*TICK`: `a.txt` = `a1`, message `c1 main`.
3. F1 on `feat` at `T0 + 2*TICK`: add `b.txt` = `b`, message `f1 feat`.
4. M1 on `main` at `T0 + 3*TICK`: `git merge --no-ff --no-edit -m "m1 merge feat" feat`.
5. F2 on `feat` at `T0 + 4*TICK`: `git merge --no-ff --no-edit -m "f2 merge main" <C1 id>` (C1 is `main^1` at this point).
6. C2 on `main` at `T0 + 5*TICK`: `git rm -q q`, add `new/y` = `y`, message `c2 main`.
7. F3 on `feat`, dated `T0 + 30` (older than its parent F2: the clock skew): `git mv f/x f/z`, replace the file `p` with a symlink to `a.txt`, message `f3 skewed`.
8. F4 on `feat` at `T0 + 6*TICK`: `b.txt` = `b2`, message `f4 feat`.
9. Finish with `main` checked out. The builder fails with a message unless `git merge-base --all main feat` prints exactly two ids (C1 and F1) and F3's committer time is lower than F2's.
Known answers (the reads plans rely on them): `main` = C2 and `feat` = F4; `feat~3` = F1; merge-base candidates of `main`/`feat` are {C1, F1}; merge-base of `main`/`feat~3` is F1.
